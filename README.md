# Geo-analyser
 Built an SEO analytics tool to track brand visibility across both traditional SERPs and AI-powered search features

(Google AI Overviews, Bing Copilot).

– Implemented automated scraping pipelines using Python (Requests, BeautifulSoup, Playwright) to extract rank-

ings, featured snippets, and AI-generated answers.

– Designed brand mention detection and visibility scoring system to quantify performance in AI-generated responses.

– Developed interactive dashboards with Chart.js and Plotly to visualize keyword rankings, AI presence rates, and

competitor comparisons.

– Optimized for lightweight, in-house deployment on CPU-only hardware using SQLite and Python without external

APIs
